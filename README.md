# Aplikasi Katalog Produk Flutter - Tugas PPB

Aplikasi seluler berbasis Flutter yang terintegrasi dengan DummyJSON API.

Wajah dan penjelasan demo aplikasi dapat disaksikan melalui tautan YouTube berikut:
* **Link YouTube:** [https://youtu.be/SneqFdkDH6U?si=Gika7J1V_OJeS_9r]

## ✨ Fitur Utama
- **Halaman Depan:** Menampilkan daftar produk secara dinamis dari API dengan tema warna yang selaras.
- **Pencarian Produk:** Kolom *search* yang fungsional untuk mencari produk.
- **Detail Produk:** Menampilkan informasi lengkap (gambar, kategori, stok, harga, deskripsi).
- **Tambah & Edit Produk:** Mendukung operasi tambah dan pembaruan data produk.
